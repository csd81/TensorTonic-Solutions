# Corpus

`corpus.txt` is a 50,000-character excerpt from Tiny Shakespeare:

https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt

Tiny Shakespeare is a public-domain compilation of William Shakespeare's plays.
The excerpt is bundled so the LLM demo runs offline. To use a different text,
pass `--corpus path/to/text.txt`.
