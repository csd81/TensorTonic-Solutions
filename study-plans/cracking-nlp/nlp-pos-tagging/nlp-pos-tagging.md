# <span style="font-size: 20px;">POS Tagging</span>

<span style="font-size: 14px;">Part-of-speech (POS) tagging assigns a grammatical category (noun, verb, adjective, etc.) to each token in a sentence. It is one of the fundamental sequence labeling tasks in NLP. This exercise uses a most-frequent-tag baseline: each known word receives its most frequent training tag, with ties resolved by Python string order; unseen words receive the supplied default tag. The HMM and Viterbi material below is optional background on context-sensitive tagging, not the algorithm assessed here.</span>

---

## <span style="font-size: 16px;">Optional Background: Hidden Markov Model</span>

<span style="font-size: 14px;">An HMM models a sequence of observations (words) as being generated by a sequence of hidden states (POS tags). It is defined by three probability distributions:</span>

### <span style="font-size: 14px;">Initial Probabilities</span>

$$\pi_s = P(\text{tag}_1 = s)$$

<span style="font-size: 14px;">The probability that the first token in a sentence has tag $s$.</span>

### <span style="font-size: 14px;">Transition Probabilities</span>

$$a_{s,s'} = P(\text{tag}_t = s' \mid \text{tag}_{t-1} = s)$$

<span style="font-size: 14px;">The probability of transitioning from tag $s$ to tag $s'$. Captures syntactic patterns like "adjective is likely followed by noun".</span>

### <span style="font-size: 14px;">Emission Probabilities</span>

$$b_s(w) = P(\text{word}_t = w \mid \text{tag}_t = s)$$

<span style="font-size: 14px;">The probability that a token with tag $s$ is the word $w$. Captures lexical patterns like "the" is almost always a determiner.</span>

---

## <span style="font-size: 16px;">Parameter Estimation</span>

<span style="font-size: 14px;">Given a tagged training corpus, estimate all parameters by counting with Laplace smoothing:</span>

$$\pi_s = \frac{\text{count}(s \text{ starts sentence}) + \alpha}{\text{total sentences} + \alpha \cdot |S|}$$

$$a_{s,s'} = \frac{\text{count}(s \to s') + \alpha}{\text{count}(s) + \alpha \cdot |S|}$$

$$b_s(w) = \frac{\text{count}(w, s) + \alpha}{\text{count}(s) + \alpha \cdot |V|}$$

<span style="font-size: 14px;">where $|S|$ is the number of unique tags and $|V|$ is the vocabulary size.</span>

---

## <span style="font-size: 16px;">Viterbi Algorithm</span>

<span style="font-size: 14px;">The Viterbi algorithm finds the most likely tag sequence for a given sentence using dynamic programming. It works in log-space to prevent underflow:</span>

### <span style="font-size: 14px;">Initialization ($t = 0$)</span>

$$\delta_0(s) = \log \pi_s + \log b_s(w_0)$$

### <span style="font-size: 14px;">Recursion ($t = 1, \ldots, T-1$)</span>

$$\delta_t(s) = \max_{s'} \left[ \delta_{t-1}(s') + \log a_{s',s} + \log b_s(w_t) \right]$$

$$\psi_t(s) = \arg\max_{s'} \left[ \delta_{t-1}(s') + \log a_{s',s} \right]$$

### <span style="font-size: 14px;">Termination</span>

$$s^*_T = \arg\max_s \delta_T(s)$$

### <span style="font-size: 14px;">Backtracking</span>

$$s^*_t = \psi_{t+1}(s^*_{t+1}) \quad \text{for } t = T-1, \ldots, 0$$

<span style="font-size: 14px;">The algorithm has time complexity $O(T \cdot |S|^2)$ where $T$ is the sentence length and $|S|$ is the number of tags.</span>

---

## <span style="font-size: 16px;">Unknown Words in an HMM</span>

<span style="font-size: 14px;">In an HMM, smoothing assigns nonzero emission probabilities to unseen words, so the predicted tag can depend on sequence context. In this exercise, unseen words receive the supplied default tag instead.</span>

## <span style="font-size: 16px;">Common Interview Follow-ups</span>

* <span style="font-size: 14px;">**HMM vs CRF for POS tagging?** HMMs are generative (model joint probability of tags and words) while CRFs are discriminative (model conditional probability of tags given words). CRFs can use arbitrary overlapping features and typically achieve higher accuracy</span>
* <span style="font-size: 14px;">**Why Viterbi instead of greedy decoding?** Greedy decoding picks the best tag at each position independently. Viterbi considers the entire sequence, finding the globally optimal tag sequence. A locally optimal choice at one position may force suboptimal choices later</span>
* <span style="font-size: 14px;">**Why log-space?** Multiplying many small probabilities causes numerical underflow. Log-space converts products to sums, keeping values in a manageable range. The argmax is preserved because log is monotonically increasing</span>
